# Ping pong game with a distributed embedded control system (group 20)

This project was developed by Group 20 for the course TTK4155 (Embedded and Industrial Computer Systems Design). It contains the software for the microcontrollers assembled in the hardware part of the course, which together make up an embedded ping pong system.
